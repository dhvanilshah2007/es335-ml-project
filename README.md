## 1. Project Overview & Research Question

This project studies whether multivariate sensor telemetry from turbofan engines can warn of impending failure early enough to outperform a **fixed-interval replacement schedule**.

- **Core Research Question:** *Can strictly trailing sensor history up to cycle $t$ predict remaining useful life ($RUL$) and trigger an alarm ($\text{RUL} \le w$) early enough to lower total maintenance cost compared to a fixed replacement cycle $K$?*
- **Decision Framing:** Running an engine to failure incurs catastrophic cost ($c_{\text{fail}}$), while premature replacement discards remaining useful life ($c_{\text{waste}}$). We evaluate model-triggered policies against the dev-optimal fixed schedule $K^*$ across cost ratios $c_{\text{fail}} : c_{\text{waste}} \in [10, 300]$ and report engine-level bootstrap uncertainty.

> **Important Context:** NASA C-MAPSS FD001 is generated by an engine simulator (single operating condition, high-pressure compressor degradation, zero missing values or censoring). This is a controlled benchmark study without causal or deployment claims.

## 2. Methodological Rigor & Baseline Ladder

- **Leakage-Proof Splitting (`seed=42`):** The 100 run-to-failure engines in `train_FD001.txt` are partitioned into **80 development engines** and **20 held-out test engines**. All sensor filtering, feature scaling, tuning, and alarm threshold selection ($K^*_{\text{dev}}$, $p^*_{\text{dev}}$, $\tau^*_{\text{dev}}$) use **5-fold `GroupKFold`** on the 80 development engines only.
- **Causal Trailing Pipeline (`window_k = 30`):** Drops 7 constant/near-constant sensors on training folds only and computes per-engine trailing mean, rolling standard deviation, and linear OLS drift slope over $[t - k + 1, t]$, plus engine age (`cycle`) $\rightarrow$ 43 features.
- **6-Rung Baseline Ladder:**
  - **Rung 0:** Mean RUL / Never Alarm (floor baseline)
  - **Rung 1:** Fixed-interval replacement at $K^*$ cycles (non-sensor policy baseline)
  - **Rung 2:** Age-only linear / logistic regression
  - **Rung 3:** Instantaneous sensors + Ridge, Lasso, Logistic Regression
  - **Rung 4:** Trailing trends ($k=30$) + Ridge, Lasso, Logistic Regression
  - **Rung 5:** Trailing trends ($k=30$) + Random Forest & HistGradientBoosting

## 4. Reproduction Steps

1. **Create and activate a virtual environment, then install dependencies:**
   ```bash
   python -m venv .venv
   # Windows: .venv\Scripts\activate
   # Linux/macOS: source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. **Run the pipeline end-to-end:**
   ```bash
   python scripts/verify_data.py
   python scripts/make_splits.py
   python scripts/run_eda.py
   python scripts/run_features.py
   python scripts/run_cv.py
   python scripts/run_test_evaluation.py
   ```
